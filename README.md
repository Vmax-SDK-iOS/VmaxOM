# VmaxOM

VmaxOM is a framework which enables Open Measurement viewability for Vmax Ads.

## Prerequisites

- Use Xcode 16.4 or higher
- Target iOS 13.0 or higher
- Requires a Vmax SDK

## Installation

VmaxOM is available through [Swift Package Manager](https://docs.swift.org/swiftpm/documentation/packagemanagerdocs/). To install it, simply follow the below instruction:

1.  In Xcode, install the Swift Package by navigating to **File > Add Package Dependancies...**
    
2.  In the prompt that appears, enter the below GitHub repository:
    
    ```
    https://github.com/Vmax-SDK-iOS/VmaxOM
    ```
    
3.  We recommend using the **Up to Next Major Version** option for new projects.
    
Once you're finished, Xcode resolves your package dependencies and downloads them in the background.
